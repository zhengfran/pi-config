# pi-config

Personal configuration for [Pi](https://github.com/earendil-works/pi/tree/main/packages/coding-agent), included in [`dotconfig`](https://github.com/zhengfran/dotconfig) as the `tools/ai/pi` submodule.

## Install

```bash
git clone --recurse-submodules git@github.com:zhengfran/dotconfig.git ~/dotconfig
~/dotconfig/scripts/setup-config.sh
```

The setup script links the portable resources into `~/.pi/agent`; auth, sessions, trust, and Pi-managed packages stay there untracked.

| Path                | Purpose                                                                          |
| ------------------- | -------------------------------------------------------------------------------- |
| `settings.json`     | Defaults and Pi packages                                                         |
| `global-agents.md`  | Global instructions (`~/.pi/agent/AGENTS.md`)                                    |
| `extensions/`       | `ask-user` tool, `/copy-all` command, Herdr state hook (generated by Herdr)      |
| `herdr-agents.json` | pi-herdr-agents config (`~/.pi/agent/herdr-agents/config.json`): per-role models |
| `themes/`           | `github-dark-default`                                                            |

Skills are managed by [`zzc-skills`](https://github.com/zhengfran/zzc-skills).

Subagents need Pi started inside Herdr (`HERDR_ENV=1`). Edit pi-herdr-agents in a separate clone, push, then `pi update git:github.com/zhengfran/pi-herdr-agents`; Pi's managed checkout is replaceable.

The former headless subagent runtime lives on the `archive/headless-subagents` branch.
